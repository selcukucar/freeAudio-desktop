Getting started

Open Library provides tabs for radio, favourites, recordings, timers, liked songs, podcasts, audio books and local music. The application runs without an NVDA installation.

Playback without moving focus

F8 in the main window and library stops playback or a pending connection; a second F8 plays the last saved media. The same button changes between Stop Playback (F8) and Play Last Media (F8), keeping focus for Space or Enter. A second press during a slow stop queues playback and a third cancels that request. Holding F8 does not repeat the toggle. Ctrl+Alt+Shift+S remains stop-only. The separate Play / Pause / Resume button resumes paused media. Independent recordings continue.

Keyboard access

Use Tab and Shift+Tab between controls, Ctrl+Tab and Ctrl+Shift+Tab between tabs, arrow keys in lists, and Enter to play the selected item. F1 opens this guide. Commands and Shortcuts exposes every command and lets you change global hotkeys. Leave a shortcut empty to disable it. Unavailable combinations are listed in that window.

Global shortcuts

Use Ctrl+Alt+Shift with R for radio, O for podcasts, L for audio books, U for jukebox, P for play/pause, S for stop, E for recording, I for current information and B for a bookmark. Up/Down changes volume, Left/Right navigates items and J/K rewinds/forwards live audio. Ctrl+Alt+Shift+F7/F8 changes speed; Ctrl+Shift+F7/F8 changes pitch. Commands and Shortcuts shows every binding and its availability. Use Default Shortcut restores the selected binding. Existing custom bindings are preserved.

Instant radio recording

In Radio or Favourites, right-click or press the Applications key or Shift+F10. Start Instant Recording of Playing Station records the radio currently playing, regardless of the selected list item. Success is announced after audio data arrives. Use Stop Instant Recording in the same menu to save; the complete file path is announced. Open Recordings Folder opens the destination. Changing or stopping playback does not interrupt the independent recording. Every recording has its own file.

Radio and favourites

Type a station name in Search, select a result and press Enter. Add to Favourites saves a station. Add Custom Station accepts a direct audio stream address. Search and online playback require an internet connection.

Podcasts and audio books

Subscribe to an RSS feed or search for a podcast, then select an episode and press Enter. Audio Books supports LibriVox, Gutenberg and GETEM. GETEM requires your own membership. Library entries and playback positions are saved.

Local music and bookmarks

Add files or folders from the Jukebox tab. Select files again if you move or rename them. Bookmarks for files, episodes and book chapters may include text or recorded notes. Text notes use a Windows voice so playback can wait for the note to finish.

Startup and accessibility settings

Resume last media when the application starts refers to this application, independently of screen-reader startup. Screen Reader sends notifications through a running supported screen reader; Windows Voice uses a separate Windows voice. Braille notifications are optional and require NVDA or JAWS plus a connected braille display. Leave the option unchecked if you do not use one. Notification History lets you reread and copy recent messages.

Recording, time shift and timers

Manage instant and scheduled recordings on the Recording tab. Listening can continue during recording. Exiting during an active recording asks for confirmation before stopping it. Enable the time-shift buffer in Settings to rewind supported live streams. Scheduled jobs require the application to remain open; they cannot start while the computer or application is off.

Optional audio tools

Speed, pitch and effects depend on the media type and audio engine. Music recognition and some recording conversions need FFmpeg. Select your ffmpeg.exe in Settings when required. FFmpeg is not bundled.

Profile backup and updates

Profile Backup and Restore saves settings, favourites, subscriptions, libraries, progress and bookmark notes to a ZIP file. Downloaded media, recordings and account credentials are excluded. Restore validates the archive first and applies it on the next startup, after backing up the current profile. The first launch of a new version also backs up the previous profile. Automatic update settings are hidden until a release channel is available.

Portable use and exit

Extract the complete portable ZIP. Portable preferences are stored in data next to the executable. Installed preferences are in AppData/Roaming/freeAudioDesktop under your Windows user account. Installing a new version preserves those preferences. Closing the library keeps playback running. Exit on the main window closes the application and stops playback and recording.

In-app updates

Check for Updates offers download choices. Installed copies can download, verify, install and restart. Downloads can be cancelled. Settings are preserved and the new version backs up the profile on first launch. Portable copies download a ZIP: close the application and preserve your data folder when extracting it. Packages are currently unsigned; checksum verification is not a publisher signature.

New-release notice on startup

With automatic startup checks enabled, a background check starts after about five seconds. A new version is announced once and appears on the main window update button. Focus and playback are preserved. The button opens download/install options; nothing downloads or installs without your choice. Offline or up-to-date startups remain quiet.
